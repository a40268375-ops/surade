💳 2. LIHAT PAYMENT GATEWAY DI WEBSITE
═══════════════════════════════════════════════════════════════

LANGKAH 1: Buka terminal, jalankan backend:

   cd c:\laragon\www\Surade.com\backend
   php artisan serve

LANGKAH 2: Buka terminal baru, jalankan frontend:

   cd c:\laragon\www\Surade.com\frontend
   npm run dev

LANGKAH 3: Buka browser:

   http://localhost:5173

LANGKAH 4: Login ke website

LANGKAH 5: Test Payment di Premium:
   a. Klik bisnis mana saja
   b. Scroll bawah
   c. Klik "Upgrade Premium"
   d. Pilih paket (Monthly/Quarterly/Yearly)
   e. Klik "Lanjutkan ke Pembayaran"
   f. Lihat PaymentMethodSelector muncul dengan logo bank!

   a. Login sebagai admin
   b. Klik "Admin Web"
   c. Pilih tab "Kelola Pembayaran"
   d. Lihat semua metode payment dengan:
      - Logo di setiap card
      - Toggle ON/OFF
      - Filter by kategori
      - Edit nomor rekening
      - Upload QRIS image

🔧 3. TROUBLESHOOTING - KALAU MASIH GAK KELIATAN
═══════════════════════════════════════════════════════════════

Problem: Email preview 404 Not Found
Solution:
   cd backend
   php artisan serve
   
   Lalu buka: http://localhost:8000/test-email-preview.html

───────────────────────────────────────────────────────────────

Problem: Payment selector masih error
Solution:
   1. Clear browser cache: CTRL + SHIFT + R
   2. Restart frontend: 
      cd frontend
      npm run dev
   3. Hard refresh browser

Problem: Logo payment tidak muncul

💡 TIPS: Kalau mau kirim email OTP beneran ke Gmail:
═══════════════════════════════════════════════════════════════

1. Setup App Password di Gmail:
   - Buka: https://myaccount.google.com/apppasswords
   - Generate new app password
   - Copy 16 digit code

2. Edit .env:
   MAIL_PASSWORD=paste-16-digit-code-disini

3. Test kirim email:
   cd backend
   php artisan tinker
   Mail::to('email-anda@gmail.com')->send(new \App\Mail\OtpMail('123456', 'Nama', 'registration'));

4. Check inbox: https://mail.google.com/mail/u/0/#inbox
