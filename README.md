# Surade.co.id - Portal UMKM & Direktori Digital Kecamatan Surade

Platform direktori usaha mikro, kecil, dan menengah (UMKM), potensi wisata, budaya, serta agenda event di kawasan Kecamatan Surade, Kabupaten Sukabumi, Jawa Barat.

## 🚀 Fitur Utama
- **Direktori Bisnis Terverifikasi:** Katalog usaha lokal lengkap dengan kontak WhatsApp, jam operasional, galeri, dan rute lokasi.
- **Smart Village / Desa Digital:** Profil dan potensi desa/kelurahan di wilayah Surade.
- **Iklan & Sponsorship Mandiri:** Sistem promosi banner premium teratas dan ticker berjalan dengan sistem kupon diskon.
- **Blog & Event Komunitas:** Publikasi artikel wisata, budaya Pajampangan, dan agenda festival lokal.
- **Program Referral & Afiliasi:** Kode referral unik dan sistem bagi hasil komisi untuk reseller lokal.
- **Ulasan & Rating Transparan:** Review autentik dari pelanggan dengan bintang dan balasan pemilik bisnis.

## 🛠️ Tech Stack
- **Frontend:** React 19, Tailwind CSS, Lucide Icons, React Router v7, Leaflet Map.
- **Backend:** Laravel 11, MySQL, RESTful API, Sanctum Auth.
